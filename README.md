# 🎓 ProfPulse — Student Professor Ratings & Course Survival Guide

> **Discreet, student-first faculty ratings, course survival blueprints, and constructive academic feedback with a built-in Teacher Anti-Ragging Guard.**

---

## ✨ Features

- 🛡️ **Live "Teacher Anti-Ragging" Content Filter & Guard**:
  - Real-time text analysis checks for insults, derogatory attacks, and cyber-harassment.
  - Live Quality Status Meter: **Approved** (100% Constructive), **Constructive Tone Notice**, or **Blocked by Anti-Ragging Guard**.
  - Offers instant suggestions on turning emotional venting into actionable, constructive advice for future students.
- 📊 **10-Point Scorecard Matrix**:
  - Multi-metric evaluations: *Concept Clarity*, *Grading Fairness*, *Approachability in Office Hours*, *Course Pacing & Workload*, and *Exam Predictability*.
  - Grade distribution breakdown (% of A, B, C, D/F).
  - Difficulty rating (1.0 to 5.0) & "Would Take Again" % consensus.
- 💡 **Course Survival Blueprints & Senior Pro-Tips**:
  - Breakdown of attendance policies, textbook requirements, office hours effectiveness, and exam styles.
  - Crowd-verified survival tips and helpful upvote tracking.
- ⭐ **Star / Bookmark & Comparison Tool**:
  - Save faculty to a dedicated Starred Drawer for course registration planning.
  - Side-by-side comparison of up to 3 professors simultaneously.
- 🔍 **Instant Search & Department Filters**:
  - Live search across professor names, course codes (e.g., CS106B, 18.06), departments, universities, and student tags.
- 🎨 **Clean & Responsive UI/UX**:
  - Built with modern typography, glassmorphic panels, glowing score badges, and smooth dark/light mode switching.

---

## 🚀 Tech Stack

- **Frontend**: React 18, Vite 5
- **Icons**: Lucide React
- **Animations & Effects**: Canvas Confetti, CSS Transitions & Keyframes
- **Styling**: Vanilla CSS Design System with CSS Custom Properties (Dark / Light mode)

## 🛠️ Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Locally in Development Mode
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Build for Production
```bash
npm run build
```
The optimized production bundle will be created in the `dist/` directory.

## 📜 Community Anti-Ragging Policy

ProfPulse is committed to fostering a supportive and constructive academic environment:
1. **Zero Tolerance for Personal Ragging & Harassment**: Feedback must strictly relate to teaching methodology, grading fairness, coursework, and exams.
2. **Actionable Advice Over Emotional Venting**: Explain how juniors can succeed in the course rather than resorting to non-constructive attacks.
3. **Student Privacy**: Anonymous peer monikers protect student identities.
